# L2 Monitor - Web App Rotation Editor

🎮 Telegram Web App для редактирования ротации скиллов L2 Monitor Bot

## Описание

Интерактивный редактор ротации скиллов для L2 Monitor Bot, работающий прямо внутри Telegram.

## Возможности

- ✅ Добавление/удаление скиллов
- ✅ Изменение порядка скиллов (⬆️⬇️)
- ✅ Настройка клавиш (F1-F12, 0-9, A-Z)
- ✅ Настройка задержек (в секундах)
- ✅ Переключение профилей (Default, Farm, PvP, Raid)
- ✅ Переключение персонажей (Main, Buffer)
- ✅ Адаптивный дизайн для мобильных
- ✅ Темная/светлая тема (автоматически из Telegram)

## Использование

1. Отправьте команду `/rotation` в Telegram бота
2. Нажмите кнопку "🎮 Открыть редактор"
3. Откроется Web App внутри Telegram
4. Редактируйте ротацию и сохраните

## Технологии

- Vanilla JavaScript (без фреймворков)
- Telegram Web App API
- Responsive CSS
